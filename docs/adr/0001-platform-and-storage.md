# ADR 0001：运行平台与存储边界

状态：已接受

日期：2026-08-13

## 决策

产品界面采用 TypeScript、React 与 Next 兼容的 Vinext 工程实现。最终自托管架构采用 PostgreSQL 保存身份、权限、密文和同步状态，MinIO 保存加密媒体块，Cloudflare Tunnel 提供 `qijian.everanz.com` 公网入口。

浏览器 IndexedDB 仅负责本机加密草稿、离线缓存与待同步队列，不作为多设备权威数据库。

## 原因

- 产品明确要求数据落在用户自己的服务器。
- 富媒体和多设备同步需要可靠的关系数据库与对象存储。
- 端到端加密要求服务端只处理密文。
- iPhone PWA 需要本机草稿和网络恢复后的续传队列。

## 影响

- Sites 初始工程用于快速建立可见、可验证的 PWA 前端，不替代最终 PostgreSQL/MinIO 自托管部署。
- 真实 Apple 登录与 Cloudflare 修改在外部凭据可用后接入。
- 所有本机数据都必须明确标注“本机”或“已同步”，不能混淆。
