# PWA 能力说明

- 主屏幕网页在支持的 iPhone 系统上可以接收 Web Push，但必须先添加到主屏幕，并由用户点击按钮触发授权。
- 网页只能通过 Passkey/WebAuthn 请求“设备验证”；系统可能使用 Face ID、Touch ID 或设备密码，网页不能保证具体方式。
- 网页不能直接读取 HealthKit 或活动圆环；第一版使用手动填写和用户主动选择的文件导入。
- 网页不能提供真正的 WidgetKit 桌面小组件；第一版提供应用内小组件式卡片。
- 网页无法保证获得完整 Live Photo 资源；第一版尝试配对照片与短视频，失败时显示静态照片或普通视频。
- iOS 不保证网页长期后台运行；上传会在重新打开、回到前台或网络恢复时续传。
- 音乐是否能自动播放由浏览器决定；被阻止时显示播放按钮。

以上限制会同时在产品设置中呈现，不能用假界面伪装原生能力。
