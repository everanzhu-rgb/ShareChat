# 栖笺端到端加密协议 v1

## 目的

正文、评论、位置、心情和媒体在设备端加密，服务器只处理密文、权限和最少元数据。

## 原语

- 内容：XChaCha20-Poly1305；
- 身份签名：Ed25519；
- 数据密钥封装：libsodium sealed box；
- 随机：系统 CSPRNG；
- 恢复表示：256 位熵编码为带校验的 24 词 BIP39 英文词组。

## 上下文绑定

每个密文的 AAD 包含协议版本、对象类型、对象 ID、用户或情侣空间 ID、Revision、密钥版本和可选附件块序号。密文移到另一个对象或版本后必须无法解密。

## 密钥层级

每篇手记和每个附件有独立随机 Data Key。私人 Data Key 只封装给作者范围；共享 Data Key 封装给 Couple Space Key 或授权设备。可见范围改变时重新封装 Data Key，避免重新上传大文件。

每台设备有独立加密和签名密钥。关键 envelope 必须签名。配对时双方根据规范化公钥和空间 ID 得到相同安全数字，确认后才交付 Couple Space Key。

## 恢复

恢复短语只在设备生成和输入。服务器保存由恢复派生密钥加密的账户主密钥 envelope，不接收短语或其直接哈希。当前代码已交付短语生成与校验；恢复 envelope 的 KDF 参数需在 iPhone 真机性能测试后固化。

## 当前实现状态

- `packages/crypto`：生产协议原语、AAD、封装、签名、恢复短语和安全数字已实现并有测试。
- `app/lib/crypto`：本机草稿使用 Web Crypto AES-GCM 和不可导出设备密钥，作为浏览器本机持久化层。
- 尚未完成：账户主密钥 UI、恢复 envelope、设备审批 API、附件流式分块和服务端同步。
